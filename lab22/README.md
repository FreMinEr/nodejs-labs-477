# Лабораторная работа 22

Парфёнок Иван Николаевич, группа 477. Node.js 22+, MySQL 8.4. `npm ci`, скопировать .env.example в .env и указать пароль отдельного пользователя student.

Администратор MySQL заранее создаёт базу lab477 с utf8mb4 и пользователя student с правами только на lab477.*. Пример команд: `CREATE DATABASE lab477 CHARACTER SET utf8mb4;`, `CREATE USER 'student'@'localhost' IDENTIFIED BY '<ваш пароль>';`, `GRANT ALL ON lab477.* TO 'student'@'localhost';`. Приложение не использует root.

`npm run task1` … `npm run task5`. Задание 1: `npm run task1 -- --bad-password` для ошибки аутентификации. Задания 2–5 применяют миграции автоматически. `npm run migrate`, `npm run migrate:rollback` (откат последней таблицы удаляет её учебные данные).

Задание 3 создаёт 100000 записей, сравнивает фактически измеренное потребление памяти, принудительно закрывает собственное соединение командой KILL для проверки восстановления пула. Выполняйте только в учебной базе. Повторные запуски CRUD/DAO добавляют учебные записи; большие данные вставляются идемпотентно. SQL-инъекция показана исключительно SELECT-запросом без удаления таблиц.

Задание 5: порт 3000, API /api/students, /api/groups, /api/metrics, /api/cache/stats. Batch принимает массив, любая ошибка откатывает всю транзакцию. SQL и транзакции логируются без значений параметров. Кэш GET на 60 секунд очищается при успешных изменениях. Формат группы адаптирован к 477; также принимается формат ББМО-XX-XX из методички.
