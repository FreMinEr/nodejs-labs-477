# Лабораторная работа 21

Парфёнок Иван Николаевич, группа 477. Node.js 22+, внешние зависимости не нужны.

Запуск: `npm run task1` … `npm run task5`. Проверки: `npm test`.

1. Readable с четырьмя отдельными чанками и счётчиками.
2. Writable с highWaterMark 16 и ожиданием drain.
3. pipe/pipeline, реальная ошибка ENOENT, проверка destroyed, сравнение файлов и цепочка преобразований.
4. Построчные Transform с сохранением границ UTF-8, JSONL → объекты, фильтрация, async iterator.
5. Детерминированные 10000 студентов (seed 477), порции по 100. Валидация пропускает ошибочные записи и записывает errors.log; среднее вычисляется как (grade + 4) / 2. Фильтр grade > 3. Обратное давление реального файлового приёмника, счётчики, скорость, прогресс. Отдельный замедленный запуск отменяется через 1 секунду; обычный лимит 10 секунд. Итератор создаёт второй CSV для побайтового сравнения с pipeline.

Результаты в data/, журнал errors.log; они не входят в Git. Повторный запуск перезаписывает CSV и дописывает журнал. PIPELINE_TIMEOUT_MS переопределяет обычный таймаут.
